## Why data structures matter here

The panic reductions are easier to understand once the core structures are not
abstract names. Automerge keeps compact indexes around causal history, visible
objects, sequence positions, and sync summaries. Many bugs in `desktop-patches`
were failures to reject impossible structure before later code trusted an index.

<Callout title="The recurring algorithmic move" tone="proof">
Validate the graph or index before mutating the document. If a reference cannot
be resolved in the preflight model, return an error before actor tables, op
sets, histories, or patch logs move forward.
</Callout>

## Bloom filters in sync

Bloom filters are compact set summaries. Automerge uses them in sync `Have`
messages to summarize changes the sender has added since the last shared
frontier. They can say "definitely not present" or "maybe present"; they cannot
prove membership.

<SourceCard path="rust/automerge/src/sync/bloom.rs">
The production constants target a low false-positive rate: 10 bits per entry
and 7 probes. The explainer below uses smaller defaults so collisions are easy
to see.
</SourceCard>

## Change graph closure

The change graph stores causal dependencies. A head is not just one change; it
is shorthand for that change plus every dependency reachable behind it. That is
why desktop snapshot completion can ask whether advertised heads are locally
present: if the local history has those heads, it also has their accepted
dependencies.

<SourceCard path="rust/automerge/src/change_graph.rs">
Read the `ChangeGraph` fields as a compact adjacency-list design: hashes,
parents, heads, actor sequence indexes, and caches for clock queries.
</SourceCard>

## Sequence reachability

Lists and text are not validated with numeric indexes alone. Operations point
at element ids. The `desktop-patches` sequence-key reductions reject incoming
list operations when the referenced element cannot be reached from `HEAD`, the
current document, or earlier inserts in the same incoming batch.

<SourceCard path="rust/automerge/src/op_set2/change/batch.rs">
`validate_imported_sequence_keys` builds a small graph of inserted elements and
references, walks from `HEAD`, and rejects missing insert/update/delete targets
before mutating history.
</SourceCard>
